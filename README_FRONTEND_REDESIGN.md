## 🔧 Integration Guide

### Step 1: Include Files
```html
<!-- In your HTML <head> -->
<link rel="stylesheet" href="./css/premium-effects.css">

<!-- Before closing </body> -->
<script src="./js/premium-effects.js"></script>
```

### Step 2: Use CSS Classes
```html
<div class="neon-border-animated">
  <h1 class="holographic">Premium Content</h1>
  <button class="btn shine-overlay">Click Me</button>
</div>
```

### Step 3: Initialize JavaScript
```javascript
document.addEventListener('DOMContentLoaded', () => {
  // Auto-initialized effects
  window.confetti = new ConfettiExplosion();
  window.fireworks = new Fireworks();
  
  // Optional manual initialization
  new MorphingBlobs();
  new TiltEffect('.card', 10);
});
```

## 🐛 Troubleshooting

### Effects Not Working?
1. Check browser console for errors
2. Verify CSS file is loaded
3. Verify JS file is loaded
4. Check browser compatibility
5. Test in incognito mode

### Performance Issues?
1. Reduce particle counts
2. Disable effects on mobile
3. Check for memory leaks
4. Profile with DevTools
5. Optimize images/assets

### Visual Glitches?
1. Check z-index conflicts
2. Verify CSS specificity
3. Test in different browsers
4. Clear browser cache
5. Check for CSS conflicts
